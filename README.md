## Overview

**KineticAI-AWGC** is the open computational research platform of **Dr. Andualem Belachew Workie** (see [academic profile](https://github.com/andualembelachew2/andualembelachew2) · [ORCID 0000-0003-3162-4257](https://orcid.org/0000-0003-3162-4257)) — the computational foundation of the **Kinetic Blueprint Framework** for deterministic materials design of spray-pyrolyzed apatite–wollastonite glass-ceramics (AWGC).

The platform integrates experimental observations, mechanistic kinetic analysis (Korsmeyer–Peppas transport modeling), and data-driven machine-learning baselines to establish predictive processing–structure–property relationships across the 700–1100 °C processing window.

It serves as the flagship repository of the author's [GitHub profile](https://github.com/andualembelachew2), which is centered on materials chemistry, dissolution kinetics, and open science.

## Research Assets

The repository contains reproducible research assets derived from peer-reviewed experimental studies (see `docs/publications.md`).

### Experimental Datasets

- Phase Composition (initial and SBF-evolution, XRD-quantified)
- Density Evolution
- Transport Kinetics (mass loss during SBF immersion)
- pH Evolution (interfacial microenvironment)
- Biological Response (ISO 10993-5 cell viability)

> **Scope note:** raw instrument files (diffraction spectra, SEM micrographs) are published with the source studies; this repository ships the quantified results extracted from them. See `data/README.md`.

### Computational Workflows

- Data cleaning and feature engineering
- Exploratory structure–transport analysis
- Machine-learning phase prediction (with leave-one-temperature-out validation)
- Transport-model validation (Korsmeyer–Peppas)
- Microenvironment, bioactivity, and biological-response analysis

### Scientific Outputs

- Parameter identification (Korsmeyer–Peppas n, k)
- Transport-regime classification
- Crystallization evolution analysis
- Model results and feature importance

## Reproducibility & Validation Status

This repository is validated end-to-end: every notebook executes successfully on a fresh environment from `requirements.txt`, and all committed results (model metrics, kinetic parameters, processed datasets, figures) are regenerated by the committed code. See `VALIDATION.md` for the verification report and exact numbers.

```bash
pip install -r requirements.txt
jupyter nbconvert --to notebook --execute notebooks/*.ipynb   # or open in Jupyter
python src/data_processing.py && python src/models.py
```

Key validated results (see `data/processed/model_results.csv`):

- Fixed-split phase-fraction prediction: R² ≈ 0.94 (in-domain reference).
- Leave-one-temperature-out cross-validation: R² ≈ 0.32 (linear regression) — the honest estimate of generalization to a *new* sintering temperature on this 25-sample dataset.
- Korsmeyer–Peppas transport fits: n = 0.256 (quasi-Fickian, R² = 0.9990) at 700 °C and n = 0.581 (anomalous, R² = 0.9997) at 1100 °C.

## Research Context

While developed using bioactive glass-ceramic systems, the computational principles demonstrated in **KineticAI-AWGC** are broadly applicable to predictive materials research involving:

* Structure evolution
* Transport phenomena
* Reaction kinetics
* Property evolution
* Data-driven materials design

## Scientific Workflow

```text
Thermal Processing
        ↓
Crystallization Pathways
        ↓
Phase Architecture
        ↓
Microstructure
        ↓
Transport Behavior
        ↓
Microenvironment Evolution
        ↓
Biological Response
        ↓
Predictive Materials Design
```
