## About

KineticAI-AWGC unifies experimental datasets, mechanistic kinetic modeling, and machine learning to map the **processing–structure–property relationships** of spray-pyrolyzed apatite–wollastonite glass-ceramics (AWGCs) — a bioactive materials family central to bone-regeneration research.

The repository serves as the computational foundation of the **Kinetic Blueprint Framework**, which frames material performance as the outcome of a causal chain:

```text
Thermal Processing → Crystallization Pathways → Phase Architecture → Microstructure
        → Transport Behavior → Microenvironment Evolution → Biological Response
```

The objective is to make that chain *predictable* — shifting the field from empirical bioactivity testing toward rational, computation-guided design.

The project is led by **Dr. Andualem Belachew Workie** ([GitHub profile](https://github.com/andualembelachew2/andualembelachew2) · [ORCID 0000-0003-3162-4257](https://orcid.org/0000-0003-3162-4257)), and all repository assets derive from the peer-reviewed studies listed under [Publications](#publications).

## The Kinetic Blueprint Framework

![Kinetic Blueprint Framework](figures/kinetic_blueprint_framework.png)

The framework connects processing history to functional performance along a fully traceable pathway:

```text
Thermal Processing
        ↓
Crystallization Pathways
        ↓
Phase Architecture
        ↓
Microstructure
        ↓
Transport Behavior
        ↓
Microenvironment Evolution
        ↓
Biological Response
        ↓
Predictive Materials Design
```

Although demonstrated on bioactive glass-ceramics, the underlying principles — structure evolution, transport phenomena, reaction kinetics, and data-driven design — generalize naturally to predictive materials research in other systems.

## Highlights

- **Reproducible by construction** — all ten notebooks execute end-to-end on a fresh environment, and every committed result is regenerated by the committed code ([validation report](VALIDATION.md)).
- **Mechanistic transport modeling** — Korsmeyer–Peppas kinetics classify transport regimes (quasi-Fickian → anomalous → diffusion-governed) across the 700–1100 °C processing window.
- **Honest machine-learning baselines** — phase-fraction prediction is evaluated with leave-one-temperature-out cross-validation, providing a realistic measure of generalization rather than optimistic in-sample performance.
- **FAIR research assets** — datasets with documented provenance, versioned code, and a persistent Zenodo DOI.

## Repository Structure

```text
KineticAI-AWGC/
├── data/                # Experimental and processed datasets
│   ├── raw/             #   Primary measured values (XRD-quantified phase fractions, degradation)
│   └── processed/       #   Analysis-ready datasets (ML dataset, model results, kinetics)
├── notebooks/           # 10 executable notebooks covering the full workflow (01 → 10)
├── src/                 # Reusable Python modules (data processing, models, metrics, visualization)
├── docs/                # Scientific documentation (framework, datasets, publications)

├── figures/             # Generated figures and framework illustration
├── VALIDATION.md        # End-to-end reproducibility report

```
