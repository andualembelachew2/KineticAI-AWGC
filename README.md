# KineticAI-AWGC

**Deterministic kinetic blueprints for apatite–wollastonite glass-ceramics — an open computational platform for predictive materials design.**

## About

KineticAI-AWGC integrates experimental datasets, mechanistic kinetic modeling, and data-driven machine learning to establish **processing–structure–property relationships** for spray-pyrolyzed apatite–wollastonite glass-ceramics (AWGCs) — a class of bioactive materials used in bone-regeneration research.

The platform is the computational foundation of the **Kinetic Blueprint Framework**, which treats materials performance as the outcome of a causal chain:

```text
Thermal Processing → Crystallization Pathways → Phase Architecture → Microstructure
        → Transport Behavior → Microenvironment Evolution → Biological Response
```

The goal is to make that chain *predictable* — to move from empirically testing bioactivity to rationally engineering it.

The repository is developed by **Dr. Andualem Belachew Workie** ([GitHub profile](https://github.com/andualembelachew2/andualembelachew2) · [ORCID 0000-0003-3162-4257](https://orcid.org/0000-0003-3162-4257)) and contains reproducible research assets derived from the peer-reviewed studies listed under [Publications](#publications).

## Highlights

- **Reproducible by construction** — all ten notebooks execute end-to-end on a fresh environment, and every committed result is regenerated by the committed code ([validation report](VALIDATION.md)).
- **Mechanistic transport modeling** — Korsmeyer–Peppas kinetics classify transport regimes (quasi-Fickian → anomalous → diffusion-governed) across the 700–1100 °C processing window.
- **Machine-learning baselines** — phase-fraction prediction evaluated with leave-one-temperature-out cross-validation for an honest measure of generalization.
- **FAIR research assets** — datasets with documented provenance, versioned code, and a persistent Zenodo DOI.

## Getting Started

```bash
git clone https://github.com/andualembelachew2/KineticAI-AWGC.git
cd KineticAI-AWGC
pip install -r requirements.txt

# Run the analysis pipeline
python src/data_processing.py    # build the machine-learning dataset
python src/models.py             # train and evaluate the models

# Or explore the analysis interactively
jupyter notebook notebooks/
```

### Reproducing Everything

```bash
cd notebooks
jupyter nbconvert --to notebook --execute *.ipynb
```

A full verification of notebooks, scripts, datasets, and figures is documented in [VALIDATION.md](VALIDATION.md).

## Key Validated Results

| Analysis | Result | Metric |
|----------|--------|--------|
| Transport kinetics, 700 °C | quasi-Fickian burst release | n = 0.256, R² = 0.9990 |
| Transport kinetics, 1100 °C | anomalous, diffusion-governed | n = 0.581, R² = 0.9997 |
| Phase-fraction prediction (in-domain split) | useful for interpolation | R² ≈ 0.94 |
| Phase-fraction prediction (unseen sintering temperature) | limited generalization | R² ≈ 0.32 (linear regression) |

The machine-learning models are intended as interpretable baselines on a 25-sample dataset; they interpolate well within the 700–1100 °C window but do not yet extrapolate reliably to unseen processing temperatures. This limitation is stated explicitly in [VALIDATION.md](VALIDATION.md) and reflected in `data/processed/model_results.csv`.

## Scientific Framework

![Kinetic Blueprint Framework](figures/kinetic_blueprint_framework.png)

The framework connects processing history to functional performance:

```text
Thermal Processing
        ↓
Crystallization Pathways
        ↓
Phase Architecture
        ↓
Microstructure
        ↓
Transport Behavior
        ↓
Microenvironment Evolution
        ↓
Biological Response
        ↓
Predictive Materials Design
```

While developed using bioactive glass-ceramics, the computational principles — structure evolution, transport phenomena, reaction kinetics, and data-driven design — are broadly applicable to predictive materials research in other systems.
