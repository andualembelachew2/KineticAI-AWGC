# Changelog

All notable changes to KineticAI-AWGC are documented in this file. Entries are written in the past tense, dated in ISO 8601 format, and follow the principles of semantic versioning.

## [1.0.2] — 2026-08-05

This release consolidates the corrections and enhancements arising from an independent, end-to-end evaluation of the repository. The platform now attains full reproducibility: every notebook executes successfully on a fresh environment, and all committed results are regenerated by the committed code.

### Added

- Leave-one-temperature-out cross-validation as the canonical estimate of generalization to unseen processing temperatures, reported alongside the fixed-split reference in `data/processed/model_results.csv`.
- A data-integrity and reproducibility test suite (`tests/`) codifying the invariant checks described in `VALIDATION.md`.
- A GitHub Actions validation workflow (`.github/workflows/validate.yml`) that executes the test suite, regenerates the processed datasets, and runs all notebooks in an isolated environment on every push and pull request; it is activated once the repository's workflows permission is enabled.
- Machine-readable open-science metadata: `CITATION.cff` and `.zenodo.json`.
- Documentation of data provenance and of the corrections applied during validation (`data/README.md`, `data/raw/README.md`).

### Changed

- Corrected the 700 °C initial phase composition, which previously summed to 104.14 %; the row now corresponds to the canonical values (52.20 / 4.00 / 35.80 / 8.00, summing to 100.00 %).
- Renormalized the 900 °C day-3 SBF phase-composition row to 100.00 %.
- Reconciled `Final_pH_21d` for the 700 °C condition (8.35), consistent with the day-21 record of `pH_time_series.csv`.
- Relabeled `ISO_10993_Status` entries in `biological_response.csv` to the standard ISO 10993-5 categories.
- Removed the redundant `initial_crystallinity_pct` feature (an exact linear transform of `initial_amorphous_pct`) from the machine-learning feature set.
- Regenerated the Korsmeyer–Peppas parameters from the committed time series: n = 0.256 / R² = 0.9990 (700 °C) and n = 0.581 / R² = 0.9997 (1100 °C); the corresponding documentation and results summaries now report these reproducible values.
- Rephrased the repository documentation and README to reflect the validated capabilities and the explicit generalization limits of the machine-learning baselines.
- Corrected file paths and dataset locations throughout the documentation.

### Fixed

- Notebooks 04, 05, and 08, which previously terminated with `NameError` or `KeyError` because the master dataset was not loaded; notebook 06 no longer relies on hard-coded values; notebook 07 was rewritten as an analysis of the XRD-quantified phase composition.
- Latent syntax errors (escaped quotation marks) in notebook 04.

### Removed

- The placeholder XRD dataset (`data/raw/xrd_patterns.csv`, six rows, not a genuine diffraction scan) and the associated corrupt figure.
- The `Relative_Path` column of `sem_metadata.csv`, which referenced a nonexistent `data/sem_images/` archive; the micrographs are published in the source article (Crystals 13(7):1049, 2023, Figure 3).
- Duplicate package entries in `requirements.txt`.

## [1.0.1] — 2026-08-02

Initial public release. Established the repository as the computational foundation of the Kinetic Blueprint Framework, comprising the experimental datasets, analytical notebooks, source modules, and scientific documentation derived from the peer-reviewed studies listed in `docs/publications.md`. Archived on Zenodo (DOI: 10.5281/zenodo.21759552).
