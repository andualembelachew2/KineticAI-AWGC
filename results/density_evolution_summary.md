# Density Evolution Summary

## Dataset

density_evolution.csv

## Observation

Bulk density increases with thermal processing temperature.

| Temperature (°C) | Density (g/cm³) |
|------------------|----------------|
| 700 | 2.02 |
| 800 | 2.32 |
| 900 | 2.61 |
| 1000 | 2.80 |
| 1100 | 2.78 |

## Key Finding

Thermal processing promotes structural consolidation and densification.

Maximum density is achieved near 1000°C, indicating optimal sintering and reduced porosity.

## Scientific Significance

Density evolution provides a structural link between thermal processing and phase architecture, supporting subsequent transport behavior analysis.
