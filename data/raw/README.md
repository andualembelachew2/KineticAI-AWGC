# Raw Data

This directory contains primary experimental data derived from Dr. Andualem Belachew Workie's Ph.D. research and peer-reviewed publications on spray-pyrolyzed apatite–wollastonite glass-ceramic systems.

## Contents

### XRD Dataset

Raw diffraction patterns used for:

- Crystallization analysis
- Phase identification
- Phase-evolution studies

### SEM Image Archive

Scanning electron microscopy images used for:

- Microstructural characterization
- Surface-degradation analysis
- Mineral-layer evaluation
