# Processed Data

This directory contains curated and analysis-ready datasets used throughout the KineticAI-AWGC platform and the Kinetic Blueprint framework.

The datasets integrate experimental characterization, transport behavior, microenvironment evolution, biological response, and microstructural observations.

---

## Available Datasets

### kinetic_blueprint_master.csv

Integrated dataset linking:

- Thermal processing
- Phase architecture
- Network connectivity
- Transport behavior
- Bioactivity-related properties

Key variables include:

- Phase fractions
- Bulk density
- NBO/BO ratio
- Mass loss
- Calcium release
- Silicon release
- Transport mechanism

---

### pH_time_series.csv

Time-resolved pH measurements during SBF immersion.

Purpose:

- Microenvironment evolution analysis
- Transport–pH relationships
- Bioactivity interpretation

---

### biological_response.csv

Cell-viability dataset derived from extract testing.

Purpose:

- ISO 10993 assessment
- Biological response analysis
- Validation of Kinetic Blueprint design principles

---

### sem_metadata.csv

Structured metadata describing SEM observations.

Purpose:

- Microstructural interpretation
- Morphology evolution analysis
- Surface-degradation assessment

Variables include:

- Processing condition
- Immersion condition
- Morphology description
- Figure references
