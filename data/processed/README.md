# Processed Data

This directory contains curated and analysis-ready datasets used throughout the KineticAI-AWGC platform and the Kinetic Blueprint framework.

The datasets integrate experimental characterization, transport behavior, microenvironment evolution, biological response, and microstructural observations.

---

## Available Datasets

### awgc_ml_dataset.csv

Machine-learning dataset (25 rows): SBF phase composition merged with initial phase composition, plus engineered features (crystallinity, hydroxyapatite gain). Generated by `src/data_processing.py` / notebook 01.

### model_results.csv

Regression evaluation of Linear Regression and Random Forest under two schemes:

- `fixed_80_20_split` — in-domain reference (R² ≈ 0.94)
- `leave_one_temperature_out_cv` — generalization to unseen sintering temperatures (R² ≈ 0.32 for linear regression)

Generated by `src/models.py` / notebook 03.

### feature_importance.csv

Random-forest feature importances for the phase-prediction task.

### korsmeyer_peppas_parameters.csv

Korsmeyer–Peppas fit parameters (n, k, R²) for the 700 °C and 1100 °C samples. Generated by notebook 09.

### phase_composition.csv / density_evolution.csv / ph_evolution.csv / transport_kinetics.csv

Reformatted analysis copies of the phase, density, pH, and transport datasets used by the results summaries.

### bioactivity_interpretation_summary.csv

Qualitative bioactivity interpretation per sintering temperature (generated by notebook 04).

## Source Datasets (in `data/`, not `data/processed/`)

- `data/kinetic_blueprint_master.csv` — integrated processing–structure–transport dataset
- `data/pH_time_series.csv` — time-resolved pH measurements during SBF immersion
- `data/biological_response.csv` — ISO 10993-5 cell-viability dataset
- `data/sem_metadata.csv` — SEM morphology descriptions (images in the source publication)
