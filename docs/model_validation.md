# Model Validation

## Objective

Identify the dominant transport mechanism governing mass attenuation.

## Models Evaluated

- Zero-order
- First-order
- Higuchi
- Korsmeyer-Peppas

## Best Performing Model

The Korsmeyer-Peppas model consistently produced the highest goodness-of-fit values.

### 700°C

n = 0.25

R² = 0.993

Transport regime:

Quasi-Fickian burst transport.

### 1100°C

n = 0.58

R² = 0.997

Transport regime:

Anomalous diffusion-governed transport.

## Scientific Interpretation

Thermal phase partitioning modifies transport behavior by shifting the dominant release mechanism from burst dissolution toward controlled diffusion-governed transport.
